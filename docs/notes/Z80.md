# Zilog Z80 notes

## CPC clocking

The CPC feeds the Z80 a nominal 4 MHz clock, but the Gate Array grants memory
access in aligned one-microsecond slots. Individual Z80 machine cycles are
therefore stretched to a multiple of four T-states. This is why code often has
an effective rate near 3.3 MHz even though all externally reported time in this
project is the 4 MHz T-state count.

The emulator calls the Z80 core once per T-state and exchanges address, data,
M1, MREQ, IORQ, RD, WR, RFSH, WAIT, INT and HALT pins. The Gate Array sees the
same pins on the same call. Debugger instruction stepping waits for the aligned
CPC retirement boundary; it does not freeze the other chips.

Examples pinned by the test suite:

| Instruction | Raw Z80 | CPC slots | Emulated CPC time |
|---|---:|---:|---:|
| `NOP` | 4 T | 1 | 4 T |
| `LD BC,nn` | 10 T | 3 | 12 T |
| `LD A,(nn)` | 13 T | 4 | 16 T |

## Instruction behavior

The vendored `floooh/chips` core implements the documented instruction set,
prefix combinations, interrupts, refresh cycles and common undocumented
opcodes. The project wrapper retains an NMOS Q latch so SCF and CCF obtain
undocumented flag bits 3 and 5 from the correct source, and corrects WZ/MEMPTR
after CPIR/CPDR and repeating IN/OUT block instructions.

PC reported by MCP is the address of the instruction currently in progress,
not the core's already-prefetched internal PC. Changing registers or calling
`jump` rebuilds the opening fetch and drops any partial decode.

## Interrupts

The Gate Array generates `/INT` from its 6-bit horizontal-sync counter. The Z80
acknowledges it through an M1+IORQ cycle, so IM 0, 1 and 2 are handled on the
same bus as ordinary requests. The Gate Array clears its interrupt request on
the acknowledge cycle, matching CPC wiring.

## Validation and limits

Automatic tests pin CPC-rounded instruction timings and exercise flags, WZ,
register mutation, HALT, firmware boot and the `xcc` program path. The exact
vendored Z80 revision is also used by the sibling Spectrum project, where all
1,356 Fuse core vectors are pinned; that provenance is useful evidence but is
not counted as a test executed in this repository.

Interrupt timing under hostile mid-instruction CRTC/Gate Array programming and
every undocumented opcode combination remain candidates for additional CPC
specific regression media.
