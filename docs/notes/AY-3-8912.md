# AY-3-8912 notes

## CPC connection

The CPC uses the AY-3-8912 variant with one eight-bit parallel I/O port. Its
audio clock is 1 MHz, derived from the Gate Array. The chip is not directly on
the Z80 I/O bus: 8255 port A carries its data, while PPI PC7 and PC6 drive BDIR
and BC1. AY port A reads the selected keyboard/joystick matrix line.

The emulator preserves this path for ordinary software. The `chips` MCP tool
also offers a direct register write solely for diagnostics.

## Register model

All sixteen addressable registers are present:

- R0-R5: twelve-bit tone periods for channels A, B and C;
- R6: five-bit noise period;
- R7: tone/noise enables and I/O direction;
- R8-R10: four-bit channel level or envelope selection;
- R11-R12: sixteen-bit envelope period;
- R13: envelope continue/attack/alternate/hold shape;
- R14: CPC keyboard/joystick port A;
- R15: absent port B on an AY-3-8912.

Register masks are applied at write time. Tone, 17-bit noise LFSR, envelope,
mixer gates and the logarithmic 16-level amplitude table advance from chip
ticks. The three channels are mixed to a single float sample and resampled from
emulated time to 8-48 kHz signed 16-bit PCM.

## Capture behavior

Starting or stopping host capture never changes AY time. Buffered playback and
file modes run as fast as MCP execution unless a speed is requested. Live mode
uses the audio device queue as a wall-clock pacer. WAV output is mono PCM, so
samples are deterministic for the same chip writes and run limits.

## Conformance boundary

Digital generator state, masks, mixer, envelope and sample scheduling are
modeled and exposed for tests. The output is an ideal mono digital mix: it does
not model the CPC analogue amplifier, monitor speaker frequency response,
board-to-board resistor tolerances, or stereo modifications. Those analogue
differences are outside an AY register/cycle claim and should not be inferred
from the WAV amplitude.
