# Intel 8255 PPI notes

## Role in the CPC

The 8255 connects the Z80 bus to the AY, keyboard, cassette and machine-status
signals. It is selected whenever A11=0. A9 and A8 choose port A, B, C or the
control register, conventionally at F4xx, F5xx, F6xx and F7xx.

## Wiring

Port A is the bidirectional AY data bus. Port C has several independent jobs:

| Bits | Connection |
|---|---|
| PC7 | AY BDIR |
| PC6 | AY BC1 |
| PC5 | cassette data output |
| PC4 | cassette motor on |
| PC3-PC0 | keyboard matrix line select |

Port B is normally input:

| Bit | Meaning in this model |
|---:|---|
| 7 | cassette input waveform |
| 6 | printer ready, low/ready |
| 5 | expansion `/EXP`, low |
| 4 | PAL refresh, high/50 Hz |
| 3-1 | distributor ID 7, Amstrad |
| 0 | live CRTC VSYNC |

The keyboard selection on PC0-PC3 feeds AY port A, matching the physical
indirection used by firmware scans rather than exposing a synthetic key port.

## Modes and bit control

Mode 0 basic input/output and the port-C bit set/reset control form used by CPC
firmware are implemented. Reset produces control word `0x9b`, after which the
firmware programs the required directions.

The generic vendored 8255 core does not implement strobed mode 1,
bidirectional mode 2, their interrupts, or input latches. The stock CPC wiring
and firmware use mode 0, so those omissions do not affect the built-in
peripherals, but software treating the PPI as a free general-purpose 8255 test
device can observe them.
